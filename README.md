# Møllely hjemmeside

Statisk one-page site for Møllely ApS, Lyngevej 265, 3540 Lynge.

- `index.html` er hele siden: HTML, CSS, JavaScript og billeder (som data-URI'er) i én fil.
- Shelterkalenderens optagne datoer ligger i `index.html` i blokken `<script type="application/json" id="shelter-state">`. Tilføj eller fjern datoer i formatet `"2026-10-17"` og commit, så er kalenderen opdateret.
- Bookinger sker pr. SMS/telefon til 21 60 09 84; der er ingen backend.

Hosting: GitHub Pages fra dette repo.
